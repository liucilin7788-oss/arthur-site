# Claude Code 自定义 Skills 集合

## 项目简介

为 Claude Code 开发的自定义技能包，让 AI 编程助手更懂中文开发者。涵盖代码审查、Bug 修复、测试生成、代码解释、代码优化等场景。

## Skills 列表

| Skill | 命令 | 功能 |
|-------|------|------|
| **review-zh** | `/review-zh` | 中文代码审查，自动检测代码质量问题 |
| **fix-zh** | `/fix-zh` | 分析错误信息，自动定位并修复 Bug |
| **test-zh** | `/test-zh` | 为指定代码自动生成单元测试 |
| **explain-zh** | `/explain-zh` | 深度解释代码逻辑和架构设计 |
| **simplify-zh** | `/simplify-zh` | 重构优化代码，消除重复 |

## 安装方式

```bash
# 克隆到 Claude Code skills 目录
git clone <repo-url> ~/.claude/skills/

# 或手动复制
cp -r skills/* ~/.claude/skills/
```
