# 头条婚姻情感全自动发文工作流

## 项目简介

一套全自动的今日头条内容创作与发布系统，专注于"长篇婚姻情感故事"赛道。通过 AI 自动生成文章、智能配图、定时发布，实现每日 5 篇高质量内容的自动化产出。

## 核心功能

| 模块 | 功能 |
|------|------|
| **热点采集** | Scrapling 爬取头条热榜/百度热搜/知乎热榜，筛选婚姻情感相关话题 |
| **AI 文章生成** | DeepSeek 大模型生成原创文章，带真实情感细节 |
| **降 AI 率** | 句式变换、口语化改写、人味细节注入 |
| **智能配图** | AI 生成匹配主题的配图，自动裁剪适配 |
| **自动发布** | Playwright 模拟浏览器操作，定时发布到头条创作者后台 |
| **数据回收** | 自动拉取阅读量、收益等数据，分析内容表现 |
| **去重检测** | MD5 + 标题相似度双重去重，防止内容重复 |
| **合规检查** | 敏感词过滤，确保内容安全 |

## 技术栈

- **Python 3.10+**
- **Playwright** — 浏览器自动化
- **DeepSeek API** — AI 文章生成
- **Scrapling** — 网页数据采集
- **Pillow** — 图片处理

## 工作流程

```
前一天 23:00  → 采集热点 + 生成文章 + 匹配配图
当天 07:50   → 第 1 篇发布
当天 09:30   → 第 2 篇发布
当天 11:30   → 第 3 篇发布
当天 15:00   → 第 4 篇发布
当天 19:00   → 第 5 篇发布
次日凌晨     → 数据回收
```

## 使用方式

```bash
python main.py --generate    # 采集热点 + 生成文章
python main.py --publish     # 按时间表自动发布
python main.py --feedback    # 回收昨日数据
python main.py --full        # 完整流程
```
