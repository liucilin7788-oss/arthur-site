# 携程旅行笔记全自动发文工作流

## 项目简介

一套全自动的携程旅行笔记创作与发布系统，通过 AI 生成真实感旅行攻略、自动配图拼接、定时发布，参与携程创作者激励计划获取收益。

## 核心功能

| 模块 | 功能 |
|------|------|
| **热点采集** | Scrapling 爬取携程热榜、抖音旅游话题、百度热搜旅游板块 |
| **AI 笔记生成** | DeepSeek 生成旅行攻略，填充真实数据（门票价格、交通、游客评价） |
| **降 AI 率** | 口语化改写、句式变换、真实细节注入 |
| **图片处理** | 免费图库获取目的地图片，PIL 两张横拼为一张（防检测），封面图优选 |
| **自动发布** | Playwright 操作携程创作者后台（we.ctrip.com），定时发布 |
| **数据回收** | 拉取阅读量、收益数据，分析哪些目的地流量高 |
| **去重检测** | 目的地 7 天不重复 + 内容 MD5 去重 |
| **合规检查** | 敏感词过滤 + 内容真实性校验 |

## 技术栈

- **Python 3.10+**
- **Playwright** — 浏览器自动化
- **DeepSeek API** — AI 笔记生成
- **Scrapling** — 网页数据采集
- **Pillow** — 图片拼接处理
- **Unsplash/Pexels API** — 免费图库

## 工作流程

```
07:00  用户手机领取携程每日激励任务
08:30  第 1 篇发布
10:30  第 2 篇发布
12:30  第 3 篇发布
14:30  第 4 篇发布
16:30  第 5 篇发布
18:30  第 6 篇发布
23:00  数据回收
```

## 使用方式

```bash
python main.py --generate       # 采集热点 + 生成笔记 + 配图
python main.py --publish        # 按时间表自动发布
python main.py --publish --slot 1  # 仅发布第 N 篇
python main.py --feedback       # 回收昨日数据
python main.py --full           # 完整流程
```

## 收益规则

- 每篇笔记：5-30 元（优质最高 100 元）
- 单号月上限：1500 元
- 要求：每天先领激励任务，再发 3 篇以上
